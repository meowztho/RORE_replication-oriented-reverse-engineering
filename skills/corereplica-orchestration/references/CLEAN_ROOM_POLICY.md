# Clean-room and Source Policy

CoreReplica studies observable functionality, workflows, information architecture and general UX patterns. It does not copy protected/private implementation material.

Allowed sources, subject to applicable terms and user authorization:

- public product/help/pricing/changelog/store pages;
- public documentation and public API documentation;
- publicly available walkthroughs/reviews;
- screenshots or recordings supplied by the user;
- the user's own authorized account used normally;
- source code the user owns or is licensed to inspect, when the task explicitly concerns that source rather than a clean-room reconstruction.

For clean-room reference reconstruction, do not:

- obtain or copy proprietary source, bundles, binaries or decompiled implementation;
- capture private/internal API contracts for the purpose of cloning them;
- bypass authentication, paywalls, rate limits or access controls;
- use another person's account or credentials;
- bulk scrape merely because automation is available;
- copy trademarks, logos, proprietary media, text/copy, licensed catalogs or other content the reference owns;
- infer that technical visibility grants permission to reuse.

If account terms materially restrict using the product to build a competitor, state the limitation and use public/otherwise authorized sources instead. This procedure is not legal advice.
